# 商业分析：可行性 / 投资分析 / 自建 vs 采购 / 市场进入

## 定位

围绕一个具体决策，比较现状（不行动）与真实替代项的价值、全周期成本、风险、约束和可实施性，给出推荐、暂缓或验证门。

**排除**：正文要求具名决策者批准或形成资源授权 → `proposal.md`；回答研究问题 → `research-report.md`；接口与实现取舍 → `technical-report.md`。

## 硬约束

| 项 | 规则 |
| --- | --- |
| 写作 | 结论前置、具体、条件化；模型只用于改变比较或暴露约束，不用管理黑话代替判断 |
| 逻辑 | 决策问题 → 现状基准 → 真实备选 → 统一口径评价（价值 / 成本 / 风险 / 约束 / 可实施性）→ 推荐与翻转条件 → 验证门 |
| 事实 | 事实、估算、假设、未知、外部依赖分开；数字标来源、时点、单位、口径和置信范围 |
| 失败 | 为预选方案找论据、没有现状基准、口径不一却排名、单一 ROI 或评分替代判断、套 SWOT、估算冒充事实、忽略全周期成本、建议未获批写成承诺 |

## HTML 组件配方

| 位置 | 组件 |
| --- | --- |
| 首屏 | `summary`（推荐 + 翻转条件）+ `highlights` + `kpis`（关键估算，`note` 写假设） |
| 选项比较 | `comparison`（含“不行动”列）+ `verdict` |
| 价值 / 成本 | 分组 `column`（各方案逐年成本）、`waterfall`（收益拆解） |
| 定位 | `quadrant`（价值 × 难度） |
| 风险 | `risk-matrix` + `risks` |
| 假设 | `evidence`（kind 标 inferred / unknown） |
| 下一步 | `actions`（验证门）+ `decisions`（status: proposed） |
