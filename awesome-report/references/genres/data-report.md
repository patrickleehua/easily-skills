# 数据报告：经营分析 / 指标报告 / 运营数据 / 销售分析

## 定位

解读已定义的指标、趋势、分布、漏斗、监控或实验观察值，回答“发生了什么、为什么重要、还不能断言什么”。

**排除**：需要设计样本回答研究问题 → `research-report.md`；比较商业选项 → `business-analysis.md`；以组织状态和下一步为主 → `status-report.md`。

## 硬约束

| 项 | 规则 |
| --- | --- |
| 写作 | 准确、可复算、少形容词；标题写发现、对象和时点 |
| 逻辑 | 关键发现与决策限制 → 指标定义与数据质量 → 总览与基线 → 必要的分维 / 分布 / 反例 → 可支持的解释与待验证假设 → 条件式行动 → 方法与来源 |
| 口径 | 核心指标标定义、单位、分子分母、总体 / 分群、时间窗、来源 / 版本、更新时间；比较必须同口径 |
| 因果 | 描述性差异不写成因果，解释标为待验证假设；统计显著不等于效应大、不等于业务胜出 |
| 缺口 | 缺定义、分母、时间或来源时标 `[指标定义待核]` `[分母待核]`，对应数值不进结论 |
| 失败 | 只列数字、隐藏分母或口径变化、不可比数据排名、挑选窗口 / 分群、图缺轴 / 单位 / 来源、伪精确、限制藏在附录 |

## 写法要点

- 每段按“观测 → 基线 / 背景 → 限制 → 含义”推进。
- 同时给绝对值、绝对变化、相对变化和长期基线；不用多余小数制造精确感。
- 覆盖、缺失、口径变化和修订若会改变解释，写在对应发现旁边，不藏附录。
- 复杂图同时给文字结论和必要精确值。

## HTML 组件配方

| 位置 | 组件 |
| --- | --- |
| 首屏 | `summary`（关键发现 + 限制）+ `kpis`（带 `delta` 与口径 `note`） |
| 指标契约 | `table`（指标 / 定义 / 分子分母 / 时间窗 / 来源）或 `glossary` |
| 趋势 | `line`（多指标同图时单位要一致） |
| 对比 | 排序 `bar`、分组 `column`（本期 vs 上期 / 目标） |
| 构成 / 贡献 | `donut` / `stacked`；变化拆解用 `waterfall` |
| 转化 | `funnel` |
| 分群 × 时间 | `heatmap` |
| 目标 | `scorecard` |
| 解释与行动 | `evidence`（观测 vs 假设）+ `actions`（条件式行动 / 验证门） |
