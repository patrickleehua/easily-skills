# 建筑 / 工程 / 地产 / 基建（含施工、设计院、监理、物业）

## 风格要点

- **形象进度 + 产值双线**：既报“干到哪了”（楼层、节点、工序），也报“干了多少钱”（产值、计量、回款）。
- **节点化与关键路径**：按合同节点、关键线路报告偏差，延误写清天数、原因和追赶措施。
- **安全质量独立区块**：安全文明施工、隐患整改、质量验收单列，“本周无事故”也要写。
- **签证变更与资金**：设计变更、签证、索赔、进度款单独列出，金额与审批状态逐项写清。
- **天气与外部因素**：影响工期的天气、停工令、材料供应单独标注，区分可控与不可控。

|---|---|---|---|---|

## 三、产值与资金
- 本周产值：{金额}，累计：{金额}（占合同额 {%}）

- 安全巡检：{次数 / 隐患数 / 整改闭环率}

- {事项 — 金额 — 状态 — 需要谁决定}

- {部位 / 工序 + 完成标准 + 时间}

## 日 / 月差异

- **日报（施工日志式）**：天气、出勤人数与机械、完成部位、材料进场、安全检查、次日安排。
- **月报**：形象进度对比图、产值与计划对比、资金计划、关键线路分析、安全质量统计、下月节点与资源计划。

## 复盘要点

工期延误和质量事故复盘写：时间线 + 原因（鱼骨：人 / 机 / 料 / 法 / 环 / 设计）+ 纠偏措施（资源增加、工序调整、方案优化）+ 对后续节点的影响评估。

## 用词风格

✅ 3# 楼主体结构施工至 18 层（计划 20 层，滞后 4 天），主因为 9/10–9/13 连续降雨停工，已增加一个班组夜间作业，预计 9/30 前追平
❌ 施工进展顺利、基本按计划推进、安全形势平稳

## HTML 组件映射

节点进度 → `gantt`（计划 vs 实际）/ `timeline`；产值 → 分组 `column`（计划 vs 实际）+ `kpis`；资金构成 → `waterfall`；安全质量 → `kpis` + `checklist`；变更签证 → `table`（金额 + `status`）；延误原因 → `fishbone`。
