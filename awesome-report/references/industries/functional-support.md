# 职能部门：人力 / 财务 / 行政 / 法务 / IT 运维 / 采购

## 风格要点

- **服务对象视角**：职能工作的价值体现在支撑业务，进展写“支撑了谁、解决了什么、效率提升多少”。
- **流程与时效指标**：招聘周期、入职到岗率、报销时效、合同审核时长、工单响应与解决时长、采购周期。
- **合规与风险单列**：劳动用工、税务、合同、数据安全、审计发现等单独成节。
- **制度与项目分开**：日常运营（量与时效）和改进项目（制度建设、系统上线）分开汇报。
- **数据敏感**：薪酬、个人信息、未公开财务数据只在授权范围内出现，对外版本脱敏。

## 周报模板

```markdown
# {部门} 周报 - {日期区间} | {汇报人}

## 一、核心结论
{本周最重要的交付或风险}

## 二、日常运营
| 事项 | 本周量 | 时效 | 目标 | 说明 |
|------|--------|------|------|------|
| （招聘到岗 / 报销单 / 合同审核 / IT 工单 / 采购单） | | | | |

## 三、重点项目
1. {项目 — 阶段 — 进展 — 下一节点}

## 四、合规与风险
- {事项 — 影响 — 处置 — 需要的支持}

## 五、下周计划
- {任务 + 负责人 + 完成标准 + 时间}
```

## 各职能关注点

| 职能 | 核心指标 | 常见重点项目 |
| --- | --- | --- |
| 人力 | 编制与在岗、招聘周期、到岗率、离职率、培训覆盖 | 绩效改革、组织调整、校招 |
| 财务 | 预算执行率、费用时效、回款、应收账龄、关账时效 | 预算编制、税务筹划、系统上线 |
| 行政 | 服务工单时效、满意度、办公成本 | 搬迁、资产盘点、供应商更换 |
| 法务 | 合同审核量与时效、诉讼案件、合规培训 | 制度修订、合规体系建设 |
| IT 运维 | 可用性、工单响应 / 解决时长、安全事件 | 系统上线、迁移、安全加固 |
| 采购 | 采购周期、降本金额、供应商交付准时率 | 集采、供应商评审 |

## 用词风格

✅ 本周审核合同 46 份，平均时长 1.8 个工作日（目标 ≤2 天），退回修改 7 份，主因为付款条款缺失
❌ 高效完成各项支撑工作、服务质量持续提升

## HTML 组件映射

量与时效 → `scorecard`（时效类用 `lower_is_better`）；趋势 → `line`；项目进度 → `rag` / `gantt`；预算执行 → `waterfall` / `progress`；工单分布 → `heatmap`（类别 × 周）；合规事项 → `risks` / `checklist`。
