# 医疗 / 医药 / 医疗器械（含医院管理、临床、药企、器械研发）

## 风格要点

- **合规与安全优先**：患者安全、不良事件、合规检查单列，不与业务进展混写；“无不良事件”也要写明统计范围。
- **口径严谨**：诊疗量、床位使用率、平均住院日、药占比、耗占比等指标写清统计口径和时间窗；临床与研发数据写样本量和置信程度。
- **隐私保护**：不出现患者姓名、病历号、身份证等可识别信息；病例用编号或脱敏描述。
- **研发 / 注册节点化**：药品和器械项目按阶段（临床前 / I–III 期 / 注册申报 / 上市后）报告里程碑和偏差。
- **措辞审慎**：疗效、安全性结论用“观察到”“提示”，证据不足不写“有效”“安全”。

## 日 / 月差异

- **日报**：当日诊疗量、危急值与不良事件、次日重点安排。
- **月报**：指标趋势表（周维度）、质控指标达成、DRG / 医保相关指标、科研与人才进展、下月重点与资源需求。
- **研发项目**：按阶段里程碑报告，写入组进度（实际 / 计划）、方案偏离、严重不良事件与监管沟通。

## 复盘要点

医疗安全事件复盘用根因分析（RCA）：时间线 + 根因（鱼骨：人员 / 设备 / 药品 / 流程 / 环境 / 沟通）+ 系统性改进（制度、流程、信息系统提示），坚持非惩罚性原则。

## 用词风格

✅ 本周手术量 312 台（环比 +4%），III 级以上不良事件 0 例（统计范围：全院上报系统）
❌ 医疗质量稳步提升、患者满意度较高、安全形势良好

## HTML 组件映射

指标对比 → `scorecard` / `kpis`；质控趋势 → `line`；不良事件 → `table`（`level` + `status`）；RCA → `fishbone` + `timeline`；研发阶段 → `steps` / `gantt`；合规检查 → `checklist`。
