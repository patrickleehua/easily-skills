# 零售 / 电商 / 消费品（含门店、平台运营、品牌、直播）

## 风格要点

- **GMV 拆解开场**：GMV = 流量 × 转化率 × 客单价；变化要拆到是哪个因子带来的。
- **同比环比都要**：大促、节假日影响大，只看环比会误判；同比写清对比口径（同一活动 / 同一周）。
- **渠道与品类分层**：按渠道（自营 / 平台 / 门店 / 直播）和品类分别报告，不只报总数。
- **库存与履约**：库存周转、缺货率、履约时效、退货率与销售同等重要。
- **活动 ROI**：投放和活动写投入、产出、ROI 和口径（GMV 口径还是毛利口径）。

```markdown

|------|------|------|------|----------|
| GMV / 访客 / 转化率 / 客单价 / 退货率 | | | | |

## 三、渠道与品类
- {渠道 / 品类 — 表现 — 原因}

|------|------|-----|-----|------|
```

## 日 / 月差异

- **日报**：昨日 GMV / 订单 / 转化 / 客单价、异常波动说明、当日活动与库存预警。
- **月报**：GMV 拆解瀑布、渠道与品类结构变化、会员与复购、活动复盘、库存健康度、下月目标与资源（预算 / 货品）。

## 复盘要点

大促复盘按“目标 → 实际（GMV 拆解）→ 流量 / 转化 / 客单价各环节偏差 → 原因 → 下次改进”；活动效果区分自然增长与活动增量，没有对照组时标注为估算。

## 用词风格

✅ 本周 GMV 386 万元（目标 360 万，达成 107%），增长主要来自客单价 +12%（满减门槛调整），访客数持平
❌ 销售火爆、流量不错、活动效果显著

## HTML 组件映射

目标达成 → `scorecard`；GMV 拆解 → `waterfall`；渠道 / 品类构成 → `donut` / `stacked`；转化链路 → `funnel`；趋势 → `line`；品类 × 周 → `heatmap`；活动 ROI → `table`（number 列）；商品定位 → `quadrant`。
