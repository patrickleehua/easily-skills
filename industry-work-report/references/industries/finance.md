# 金融 / 投资（证券、基金、信贷、保险、财务）

## 风格要点

- **数据表格为核心**：核心指标用表格（本期/上期/环比/年度目标达成率），数字精确到小数位，注明口径与数据截至日。
- **审慎措辞**：区分"事实"与"观点/判断"；预测写"预计/初步测算"并给依据；不写绝对化承诺。
- **合规红线**：不出现未公开的敏感信息、不构成投资建议的表述要标注"不构成投资建议"；对外材料脱敏（标的公司写代号）。
- **市场因素归因**：业绩波动要区分"市场 beta"与"主动操作 alpha"。
- **时间口径明确**：净值/收益类数据必须写统计区间。

```markdown
|------|------|------|------|------|
| （仓位/净值/收益/回撤等） | | | | |

## 三、本周工作
- 研究：{覆盖标的/产出报告}
- 交易：{调仓动作及理由}
- 其他：{尽调/路演/路演纪要}

## 四、风险提示与关注事项
- {风险点 + 影响程度 + 应对}

## 五、下周计划
- {事项 + 预期产出}
```

## 日/月差异

- **日报**（交易/风控岗）：晨会纪要风格——隔夜市场要点 → 今日关注事件/数据 → 待执行事项 → 风控提示。
- **月报**：加月度归因分析（收益来源分解）、对标基准超额/落后原因、下月配置思路与需合规确认事项。

## 复盘要点

投资复盘强调"决策质量 vs 结果质量"分离：按当时信息判断决策是否正确，而非只看盈亏；每笔关键操作回顾"当时逻辑 → 验证结果 → 是运气还是能力"。风控事件复盘用时间线 + 根因 + 制度补丁。

## 用词风格

✅ 截至 9 月 5 日组合净值 1.083，周涨幅 +1.2%，超额基准 +0.5pp，主要贡献来自 X 板块（+0.8pp）
❌ 这周赚了不少、市场还行、感觉后面有机会（无数据、无区间、绝对化判断）
