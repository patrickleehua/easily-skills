# 通用兜底（无法判定行业时使用）

## 风格要点

- 结论先行 + 三段式骨架：结论 → 数据 → 风险/计划。
- 中性、专业、不堆修饰；适用面广的"标准职场汇报"。
- 生成后必须问用户行业，告知可按行业风格重写。

## 周报模板

```markdown
# 周报 - {姓名} | {日期区间}

## 本周核心结论
{1-2 句}

## 一、本周完成
- {任务 1} — {结果/数据}
- {任务 2} — {结果/数据}

## 二、进行中
| 任务 | 进度 | 阻塞 | 预计完成 |
|------|------|------|----------|

## 三、风险与问题
- {描述} — {影响} — {需要的支持}（没有写"无明显风险"）

## 四、下周计划
- [ ] {任务 + 完成标准 + 时间点}

## 五、其他说明（可选）
{需领导知悉的事项}
```

## 日/月差异

- **日报**：今日完成 / 明日计划 / 问题风险，各 3 条以内。
- **月报**：加关键数据环比表、重点事项展开（3-5 件）、下月计划（必须完成/应该完成分级）。

## 复盘要点

标准 GRAI 四步（见 `references/report-types.md` 复盘节），行动项按 SMART。
