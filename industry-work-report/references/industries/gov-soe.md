# 政府 / 国企 / 事业单位（公文风格）

## 风格要点

- **公文语体**：标题用"关于……的报告"或"工作情况汇报"；结构用"一、（一）、1.、（1）"层级。
- **政治站位开头**：以贯彻上级部署/文件精神/会议精神开篇（一句话点到即止，不堆砌）。
- **成绩-问题-打算三段式**：先讲成绩（讲透），再摆问题（讲准、有分寸），后讲下一步打算（讲实）。
- **零 emoji、零表格堆砌**（数据可少量嵌入正文或附简单表格）；语言庄重、多用四字结构。
- **常用动词**：扎实推进、稳步推进、深入开展、持续加强、有序推进、全面完成、取得实效。
- **问题表述讲分寸**：写"还存在一定差距""有待进一步提升"，但要跟具体事实；不回避但措辞克制。

## 周报/阶段汇报模板

```markdown
# 关于{时间段}工作情况的报告（{姓名/科室} {日期}）

本周期内，按照{上级部署/年度工作要点}要求，聚焦{核心任务}，扎实推进各项工作，现将有关情况报告如下。

## 一、工作开展情况
（一）{重点任务一}。{具体动作 + 数据 + 成效，2-4 句}
（二）{重点任务二}。……
（三）{重点任务三}。……

## 二、存在的问题
一是个别{事项}进度与计划要求相比仍有差距，主要原因是{客观原因}；
二是{能力/机制/资源短板}有待加强。

## 三、下一步工作打算
一是{动作 + 时间节点 + 预期成效}；
二是{……}；
三是{……}。

以上报告，请审阅。
```

## 日/月差异

- **日报**（值班/专项工作）：当日任务完成情况 + 动态信息 + 待办事项 + 值班情况，简短条目式。
- **月报**：扩为"一、总体情况（数据+评价）二、重点工作完成情况（分条展开）三、存在问题 四、下月安排"，篇幅 1000-2000 字。

## 复盘要点

专项工作/活动总结用"主要做法 → 取得成效 → 存在不足 → 经验启示"四段式；经验启示部分提炼可固化为制度机制的 1-3 条。

## 用词风格

✅ 累计完成 X 项、完成率 X%、覆盖 X 个单位；已建立台账并实行销号管理
❌ emoji、口语词（搞、弄）、绝对化表述（完全解决、彻底杜绝——除非确已实现）
