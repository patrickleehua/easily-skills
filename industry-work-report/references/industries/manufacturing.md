# 制造 / 供应链 / 工程（含质量、设备、项目工程）

## 风格要点

- **数据硬指标开场**：产量、达成率、良率/合格率、交付准时率、库存周转、安全事故数。
- **问题-对策表（8D 风格）**：每个异常一条——问题描述 / 原因 / 临时措施 / 永久对策 / 责任人 / 期限。
- **5W1H + 时间线**：异常和故障用"何时/何地/什么/程度/为何/如何处理"交代。
- **安全（EHS）独立区块**：安全巡检、隐患整改、环保事项单列，哪怕"本周无异常"也要写。
- **华为"日清日结"式风格**：当日问题当日闭环，报告里体现闭环状态（已闭环/整改中 X%）。

## 日/月差异

- **日报**：当日产量/良率/停机 + 当日异常与处置 + 次日排产要点，突出"当日闭环"。
- **月报**：加指标趋势表（周维度）、Top 异常 Pareto 分析（80/20）、改善项目进度（降本/提效的量化收益）、下月排产与风险预判（物料/产能/人员）。

## 复盘要点

质量/设备事故复盘用 8D 或"时间线 + 根因（5 Why/鱼骨图）+ 永久对策 + 横向展开（同类产线/工序排查）"；强调对策落到 FMEA/作业标准/点检表更新等制度层面，并验证有效性（对策后连续 X 批数据）。

## 用词风格

✅ 良率 96.2%（目标 97%，缺口 0.8pp，主因为 X 工序参数漂移，已对策并于 9/5 验证 3 批恢复至 97.1%）
❌ 良率有点低、设备偶尔出问题、下周整改
