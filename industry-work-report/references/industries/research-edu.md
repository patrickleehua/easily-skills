# 科研 / 教育（高校、研究所、教师）

## 风格要点

- **课题/论文为主线**：进展按"课题节点 → 实验/写作 → 产出"组织，写清与计划节点（如开题、中期、结题）的对照。
- **产出可数**：论文（投稿/返修/接收）、专利、会议摘要、数据集、代码仓库，各有明确状态。
- **学术诚实**：负面结果照实写（实验失败、投稿被拒及下一步），这是科研报告常态。
- **规范引用**：涉及合作者/导师的署名与分工要写清；学生汇报附导师沟通情况。

## 周报模板

```markdown
# 科研周报 - {姓名} | {日期区间}

## 一、本周进展
### 课题：{课题名}（节点：{当前所处阶段}）
- 实验：{做了什么 + 结果 + 数据结论}
- 论文：{章节/稿件推进至 X}
- 计划对照：{超前/按计划/滞后 X 天，原因}

## 二、产出与提交
- {论文/专利/报告：状态（撰写中/已投稿/返修中/已接收）}

## 三、问题与讨论点
- {技术问题/数据问题，拟采取的方案}
- {需要与导师/合作者讨论的问题}

## 四、下周计划
- {事项 + 预期完成标准}
```

## 日/月差异

- **日报**（课题组要求）：当日实验/阅读/写作记录 + 明日安排，条目式，突出"当天推进了什么"。
- **月报**：加课题进度总表（计划节点 vs 实际）、当月产出汇总、文献阅读清单（关键文献 + 一句话收获）、下月节点风险预判。

## 复盘要点

课题阶段性复盘按"研究设计回顾 → 数据/结果评估 → 方法论反思（哪些实验设计有效/无效）→ 下一阶段调整"；投稿被拒复盘要拆审稿意见逐条回应策略。

## 用词风格

✅ 实验 A 组（n=30）结果显著低于预期（p=0.03），已排除试剂批次因素，下周补做对照
❌ 实验还算成功、论文写得差不多了、进展正常（无节点对照、无数据）
