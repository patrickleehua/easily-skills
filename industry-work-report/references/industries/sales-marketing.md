# 销售 / 市场 / 商务

## 风格要点

- **漏斗思维**：线索 → 商机 → 报价 → 谈判 → 成交，报告按阶段组织。
- **数据表格**：拜访量、新增线索、成交单数/金额、转化率，全部环比。
- **客户颗粒度**：重点客户单列一行一个动作（下一步动作 + 时间 + 需要的支持）。
- **钱和人来写**：所有进展最终落到"金额/单数/日期"。
- **流失也要写**：丢单原因分类（价格/竞品/需求消失/内部变更），指导策略调整。

## 周报模板

```markdown
# 销售周报 - {姓名/团队} | {日期区间}

## 一、本周关键数据
| 指标 | 本周 | 上周 | 环比 | 月度目标达成率 |
|------|------|------|------|----------------|
| 拜访/触达 | | | | |
| 新增线索 | | | | |
| 商机推进 | | | | |
| 成交单数/金额 | | | | |

## 二、重点客户进展
| 客户 | 阶段 | 金额 | 风险 | 下一步动作 | 时间 |
|------|------|------|------|------------|------|
| （脱敏简称） | | | | | |

## 三、本周亮点与丢单
- 亮点：{成交/突破 + 原因}
- 丢单/流失：{客户 + 原因分类}

## 四、风险与需要的支持
- {如价格授权、售前资源、市场物料}

## 五、下周计划
- {动作 + 目标金额/单数 + 时间}
```

## 日/月差异

- **日报**：当日拜访/触达明细 + 商机推进 + 明日拜访安排 + 需协调（常见于快消/渠道/电销团队）。
- **月报**：加渠道/区域拆分表、转化率漏斗分析（环比变化及归因）、大客户季度推进策略、下月目标分解到周。
- **市场岗**：模板中"客户"区块换成"活动/内容/投放"（曝光、线索成本 CPL、转化、ROI）。

## 复盘要点

丢单复盘按"决策链"还原：关键人是谁、我们的方案输在哪个环节（价格/关系/方案匹配度/时机）；赢单复盘提炼可复制打法（话术/案例/渠道）。

## 用词风格

✅ 推进 XX 项目至商务谈判，预计 9 月底前签单（¥50 万），风险为竞品低价 15%，建议授权 95 折
❌ 客户聊得不错、在跟进了、应该快成了
