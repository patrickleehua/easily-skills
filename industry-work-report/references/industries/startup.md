# 创业 / 小团队（一人公司、早期初创）

## 风格要点（源自理想汽车"本周要事"、YC 周报风格）

- **极简**：一页以内，只写"本周要事 3-5 件"，砍掉一切形式化区块。
- **增长与验证导向**：写"验证了什么假设、数据证据、下一步实验"，而不是"做了什么"。
- **钱和风险直说**：现金流、获客成本、转化数据直接摆出来。
- **给自己看**：很多场景是创始人写给自己的复盘或给投资人的简报——前者可以口语化，后者按"进展/数据/求助"三段。

## 周报模板（创始人自查版）

```markdown
# 本周要事 - {日期}

## 本周要事回顾
1. {要事} — 结果：{数据/结论} — 判断：{有效/无效，为什么}
2. ……

## 关键数据
- {获客/收入/留存/获客成本等，环比}

## 本周认知更新
- {验证了什么假设 / 推翻了什么假设}

## 下周要事（≤3 件）
- {要事 + 判断标准：做到什么程度算成}

## 卡点与需要的帮助
- {……}
```

## 日/月差异

- **日报**：只写"今日 1-3 件要事 + 完成情况"，一分钟版本。
- **月报（给投资人/自己）**：Metrics（收入/MRR/用户/留存，环比表格）→ Highlights → Lowlights（直说问题）→ Asks（需要的人脉/资源/决策）→ Next month focus。

## 复盘要点

按"假设 → 实验 → 数据 → 认知"闭环复盘：这阶段的核心假设是什么、做了什么验证、数据支持还是推翻、下一步假设是什么。失败实验重点复盘"是假设错了还是执行不到位"。

## 用词风格

✅ 落地页 A/B 测试转化 4.1% vs 2.8%，验证"价格敏感"假设不成立，下周转向 X 方案
❌ 本周很忙、感觉方向是对的、稳步推进（无数据、无判断）
