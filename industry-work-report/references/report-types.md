# 报告类型结构差异

生成前先确定类型。各类型结构要点与篇幅约束如下（行业模板会在其基础上叠加风格要求）。

## 日报

- **定位**：当天动作记录 + 明日安排，供直属上级快速扫一眼。
- **篇幅**：≤300 字，5 分钟写完的密度。
- **结构**：今日完成（3-5 条）→ 进行中/未完成（含原因）→ 明日计划（1-3 条）→ 风险/需协调（没有写"无"）。
- **要点**：不写感想，不写周级总结；每条一个动作 + 一个结果。新人和外派岗位常被要求日报，重点是"让领导看到你在推进"。

## 周报

- **定位**：辅助上级决策，不是汇报流水账。核心三块：进展 / 风险 / 下周计划。
- **篇幅**：500-800 字（除非公司有字数要求）。
- **结构**：本周核心结论（1-2 句）→ 关键进展（按优先级，带数据）→ 风险与需要的支持 → 下周计划（≤5 条，每条有完成标准 + 时间点）。
- **要点**：进展要写"完成度 + 带来的结果"；风险三要素（描述/影响/支持）；可关联 OKR/KR 进度（互联网风格）。

## 月报

- **定位**：月度复盘 + 趋势分析 + 下月重点，写给上级和间接上级看。
- **篇幅**：800-1500 字。
- **结构**：月度总览（核心结论 + 状态）→ 关键数据（环比/同比表格）→ 重点事项详情（只展开 3-5 件大事）→ 问题与对策 → 下月计划与需要的资源/决策。
- **要点**：先汇总当月周报再写；必须有数据对比表；下月计划要区分"必须完成 / 应该完成"；列出需要上级决策的事项。

## 季报

- **定位**：对照季度目标（OKR/KPI）的达成评估 + 趋势 + 下季度策略。
- **结构**：季度结论 → 目标达成度（逐条 KR：目标值/实际值/差距）→ 复盘亮点与不足 → 下季度目标与策略调整 → 资源请求。

## 复盘

- **定位**：从经验中提炼可复用的规律，不是追责。
- **默认框架 GRAI**：
  - **G 目标回顾**：当初的目标是什么？成功标准是什么？是否清晰可衡量？
  - **R 结果评估**：实际发生了什么？与目标对比，亮点和不足各是什么？（用数据说话）
  - **A 原因分析**：差距为什么产生？用 5 Whys 追根因，区分主观/客观、事实/观点。
  - **I 规律总结**：学到什么？哪些可复用？产出 SMART 或 KISS（Keep/Improve/Start/Stop）行动项。
- **原则**：对事不对人；行动项必须有"动作 + 负责人 + 截止时间 + 预期效果"，拒绝"加强沟通"这类空口号。
- **篇幅**：按事件复杂度，通常 600-1500 字。

## 类型换算关系

写月报优先消费周报，写周报优先消费日报，写复盘优先消费周报/月报——先找上游材料，找不到才让用户从头口述。
